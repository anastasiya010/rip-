# Лабораторная 1 — Базовый интерфейс (без JS)

Тема: расчет дозы лекарственного препарата для ребенка.

## Запуск

1. Установите Go 1.20+.
2. При желании укажите публичный URL Minio через переменную окружения `MINIO_PUBLIC_BASE` (например, `http://localhost:9000/bucket`). Если не указано, изображения берутся из каталога `static/img`.
3. Поместите изображения в `static/img` с именами: `nurofen.png`, `pentalgin.png`, `ginkoum.png`, `cytovir.png`, `rinza.png`, `favicon.png`.
4. Запуск (Windows PowerShell):

```bash
$env:MINIO_PUBLIC_BASE=""
go run .
```

Откройте `http://localhost:8080/catalog`.

## Страницы (все GET)
- `/catalog` — список услуг, фильтр по названию через `?q=`; карточка заявки с количеством услуг (считается на сервере).
- `/service?id=ID` — подробности услуги, изображение и описание.
- `/order?id=ID` — состав заявки: поля заявки, карточки услуг строками (слева направо), справа м-м поле (нередактируемое) и итоговый результат расчета.

Данные берутся из двух коллекций в памяти: массив услуг и словарь заявок. Без БД. Без JavaScript. Стили вынесены в `static/css/style.css`.

Методические указания: README лабораторной — https://github.com/iu5git/Web/blob/main/tutorials/lab1-go/README.md
